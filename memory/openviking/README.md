# OPENVIKING ADAPTER (NOVEL OS V2.2)

The **OpenViking Adapter** provides native storage, hierarchical indexing, semantic vector search, and context assembly for long webnovel production.

## Core Capabilities
- `viking://` URI namespace management
- L0 (Abstract) / L1 (Overview) / L2 (Details) hierarchical extraction
- `find()` and `search(mode="context")`
- Multi-model rerank and `retrieval_trace`
- Health check and strict non-silent fallback
