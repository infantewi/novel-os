# NOVEL MEMORY GOVERNOR (NOVEL OS V2.2)

The **Novel Memory Governor** is the authoritative governance layer sitting between Master Orchestrator/Workers and the OpenViking storage/retrieval engine.

## Core Mandates
1. **Zero-Trust Memory Proposal**: Workers can only propose `MemoryDelta` objects; direct writes to OpenViking are strictly forbidden.
2. **Canon & Knowledge Conflict Gate**: Intercepts contradictions in realm, powers, timelines, and unrevealed knowledge boundaries.
3. **Atomic Commit & Provenance**: Ensures all persisted memories carry origin chapter, cryptographic hash, and transactional safety.
