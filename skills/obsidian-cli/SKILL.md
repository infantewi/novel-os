# Obsidian CLI Skill

Provides reference for driving Obsidian vaults and managing notes natively.

## Common Operations
- Opening vaults: `obsidian open <vault-path>`
- Searching notes: native vault search and indexing
- Graph traversal: navigating wikilink backlink graphs
