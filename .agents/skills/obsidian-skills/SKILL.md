# Obsidian Skills (kepano/obsidian-skills)

Native Agent Skill suite for interacting with Obsidian vaults, adhering to the Agent Skills specification.

## Capabilities
- **obsidian-markdown**: Wikilinks (`[[Page]]`), Embeds (`![[File]]`), Callouts (`> [!info]`), Properties (YAML frontmatter).
- **vault-structure**: Hierarchical note organizations, MOCs (Maps of Content), bidirectional linking.
- **native-isolation**: Operates purely on standard markdown files within the target vault directory.
