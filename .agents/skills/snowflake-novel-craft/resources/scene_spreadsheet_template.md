# 场景清单规划表模板（Scene Spreadsheet Template）

> 本模板依据《雪花写作法》第八步/第九步及《如何用雪花写作法创作动人场景》设计。全书在动笔起草前，建议全部拆解为原子场景并填入此表，用于统揽故事节奏、规避视角跳跃与确保每一章均有扎实冲突。

---

## 场景清单字段说明

| 字段名 | 必填 | 说明 |
| :--- | :--- | :--- |
| **序号 (Scene#)** | 是 | 全书场景物理编号（如 S01, S02...） |
| **对应章节 (Chapter)** | 是 | 归属的小说章节编号（通常一个章节包含 1-2 个场景） |
| **视点人物 (POV)** | 是 | **必须且只能有且仅有一个人**！严禁多视角混写 |
| **时空地点 (Setting)** | 是 | 场景发生的具体物理位置与时间节点（如：林家后山祖祠·深夜） |
| **场景模式 (Mode)** | 是 | `主动型 (Proactive)` 或 `被动/反应型 (Reactive)` |
| **核心事件概要 (Summary)** | 是 | 用 1-2 句话概括本场景发生了什么具象物理事件 |
| **场景推进动力 (Driver)** | 是 | **主动型**：`目标 ➔ 冲突 ➔ 挫折 (No / No+ / Yes, but)`<br>**反应型**：`反应 ➔ 困境 ➔ 决定 (锚定新目标)` |
| **预估字数 (Word Count)** | 否 | 场景篇幅（如：2500 字） |
| **完成状态 (Status)** | 是 | `未开始` / `规划中` / `初稿已完` / `精修完毕` |
