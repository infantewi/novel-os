## 步骤一：一句话概括（Logline / 25字以内）
> 严禁出现角色姓名。必须包含：主角特征身份 + 核心危机 + 核心阻碍 + 终极目标。

```text

```

## 步骤二：一段式概括与三大灾难（Five-Sentence Paragraph）
> 必须且仅由五句话构成，奠定三幕四区大纲。

```text
1. [起：日常背景与诱发事件]：
2. [承：第一场大灾难（25%）]：
3. [转：第二场大灾难 / 中点危机（50%）]：
4. [落：第三场大灾难 / 绝望至暗时刻（75%）]：
5. [结：高潮决战与最终归宿（100%）]：
```
