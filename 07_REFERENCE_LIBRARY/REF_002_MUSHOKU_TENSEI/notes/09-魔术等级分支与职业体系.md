# 魔术等级、分支与职业体系

> 本笔记整理自用户提供的英文设定，主要用于分析魔术系统如何与战斗、制度和社会分工结合。它不是对原作的逐字翻译，也不应直接复制到原创作品中。

## 一句话记忆

魔术等级表示魔力成本与术式规模，不等于施术者的综合战斗力；真正的实力还取决于知识、速度、控制、适性、装备、战术和社会资源。

## 七级魔术等级

按魔力消耗和术式规模，大致分为：

`初级` → `中级` → `高级` → `圣级` → `王级` → `帝级` → `神级`

### 规模递进

- 初级：单体、小范围、基础用途
- 中级：更强的单体攻击或较复杂的功能
- 高级：通常开始具备范围破坏能力
- 圣级：可以大范围影响战场或城市区域
- 王级：改变大型自然现象，或把自然力量集中为攻击
- 帝级：破坏力接近战略级灾害
- 神级：接近传说、国家机密或改变生死与世界规则的领域

等级之间不是线性增长，而更像数量级增长。低一级术式可能相差数倍，高一级术式则可能直接改变战场规模。

## 魔术分类

### 攻击魔术

“攻击”指主要用于战斗，不代表每个术式只能杀伤。

也可以用于：

- 取水
- 清洁
- 降雨
- 改造环境
- 制造工具

低等级攻击魔术适合冒险和实战，高等级攻击魔术虽然威力巨大，却可能不适合迷宫或普通任务，因为容易误伤、破坏环境或引发政治后果。

### 治疗魔术

可以理解为针对身体损伤的恢复术，包括：

- 擦伤、割伤和瘀伤
- 骨折
- 严重创伤
- 肢体接合
- 肢体再生

高等级治疗术的具体效果依赖世界对人体的理解。魔术不能治疗施术者尚未理解的疾病或身体结构问题。

治疗术通常需要接触或近距离施展，因为魔力必须准确作用于另一个活体。

### 解毒与净化魔术

用于排除体内有害因素，例如：

- 普通毒素
- 魔物的剧毒
- 疾病
- 晕船
- 酒精中毒和宿醉

低等级可以处理常见问题，高等级则针对稀有疾病、特殊毒素和魔物毒素。中级以上往往需要记忆大量超长咏唱，因此这是一种知识和记忆负担很重的专业领域。

国家可能把高等级毒药和解毒术当作军事机密，形成“毒药与解药的军备竞赛”。

### 结界魔术

结界用于制造防护、隔离或封锁空间。

可能防御：

- 火焰和寒冷
- 物理攻击
- 魔术攻击
- 特定属性

低等级可以用咏唱发动，高等级通常需要魔法阵，因为术式复杂、持续时间长、消耗高，而且需要稳定维持。

结界技术容易被宗教或国家垄断，因此它不仅是魔术问题，也是知识控制和政治权力问题。

### 神圣魔术

主要针对幽灵、亡灵、吸血鬼、气态生命或其他非实体目标。

它的价值不只在威力，而在于能够攻击普通物理手段难以触及的敌人。某些高级剑士也可能通过特殊技艺斩击灵体。

### 附魔

附魔是把魔法阵永久刻入物品，使普通人也能使用魔术工具。

特点：

- 需要设计和固定魔法阵
- 由使用者提供魔力
- 可以制造类似“魔法枪”的工具
- 效果和魔力消耗可以预先定制
- 进步主要依赖创意、材料和术式设计，而非魔力池大小

附魔可以用于：

- 魔杖和法杖
- 攻击工具
- 城市供暖与除雪
- 工业生产
- 日常生活设施

### 召唤魔术

召唤是把生物、物体或由魔力构成的实体呼唤到身边。

#### 使魔召唤

召唤真实存在的魔物或生物。高智能目标更难控制，但能独立思考、适应环境和执行复杂命令。

#### 精灵召唤

更接近用魔力制造人工实体。它们通常容易控制，但行动模式固定。复杂的精灵可以伪装成具有独立人格的生命。

#### 灯光精灵

简单的浮空光源，可以听懂基础指令，持续时间取决于注入的魔力。它虽然弱小，却非常适合冒险者探索黑暗区域。

### 传送魔术

传送用于把人或物从一个地点移动到另一个地点，与召唤魔术互为两面：

- 召唤：把目标带到自己这里
- 传送：把目标送离原地点

难点是准确确定抵达位置。失控传送可能把人送到高空、海中、怪物巢穴或其他致命地点，因此传送术通常被视为禁忌。

连接两个固定魔法阵后，传送可以变得稳定，但这种技术可能失传或被刻意隐藏。

## 其他地方性魔术

不同种族可能发展出独有魔术：

- 兽族的声音魔术
- 某些族群的催眠术
- 矮人的火与土属性锻造术
- 种族天赋的心灵感应
- 对气息、精神或魔力的特殊感知
- 神子、诅咒者和魔物的随机能力

这说明魔术体系不必由单一文明垄断。族群的身体结构、生活环境和文化需求都可以产生独特分支。

## 占卜与反魔术

### 占卜

通过魔力寻找未来或未知信息。由于结果模糊、精度不稳定，它通常受到怀疑，也很少有人愿意专门研究。

### 反魔术

魔法师对决时主要有三种防御思路：

1. 用结界挡住攻击
2. 用相克或同属性术式直接抵消
3. 使用干扰魔力的特殊技巧

反制要求施术者在极短时间内完成识别、咏唱、定位和威力匹配。缩短咏唱在这里尤其重要。

会无咏唱魔术的对手会大幅提高反制难度，因为防守者看不到咏唱过程，无法提前判断术式。

## 魔术师的职业路径

### 冒险者魔术师

重点是初级和中级攻击魔术，服务于：

- 远程输出
- 掩护队友
- 处理普通怪物
- 应对复杂环境

高级魔术适合大型任务，但圣级以上的范围术式在迷宫中可能过于危险。

### 治疗师

负责让队伍能够连续行动，不因受伤而被迫撤退。

高等级治疗师数量少、需求高，也可能转向城市医疗、贵族服务或高价私人诊疗。

### 研究者

研究魔术原理、术式结构和新的魔法阵。研究者的价值主要来自理解力和创造力，不一定来自战斗力。

### 宫廷魔术师

服务于国王、贵族或富商，工作可能包括：

- 护卫
- 治疗
- 战场支援
- 国家研究
- 政治咨询

宫廷魔术师能否获得高位，不只取决于力量，也取决于社交、忠诚、判断力和政治能力。

### 自由职业者

魔术师也可以通过临时服务谋生，例如：

- 家庭教师
- 农业灌溉和降雨
- 建筑和土木辅助
- 乡村医疗
- 冒险者急救
- 除雪、供暖和清洁

偏远地区往往缺少魔术师，因此一个普通水平的魔术师也可能在那里拥有很高的社会价值。

## 对原创世界观的启发

1. 等级表示术式规模，不代表个人综合实力。
2. 魔术分支应有不同的知识门槛、社会价值和政治限制。
3. 高威力术式未必适合实战，场地和误伤风险同样重要。
4. 治疗、解毒、结界和附魔可以形成独立职业，而不是战斗魔法的附属品。
5. 传送术的危险性可以直接制造禁忌、事故和国家封锁。
6. 魔术师的职业选择由兴趣、天赋、资源、教育机会和社会需求共同决定。
7. 魔术学院、宗教组织、国家和公会可以围绕知识所有权产生长期冲突。

## 记忆口诀

**等级看规模，分支看用途，战斗看组合，职业看社会需求。**
