# 日常与危机节奏

## 基本循环

`日常建立感情` → `小冲突暴露缺陷` → `大危机迫使选择` → `事后用新日常展示变化`

## 为什么日常重要

日常让读者熟悉人物的具体生活。危机发生时，读者失去的就不只是一个抽象的“同伴”，而是一种刚刚建立起来的生活。

## 日常场景可以承担的功能

- 展示人物习惯
- 暴露关系中的不平衡
- 埋下未来冲突的线索
- 让配角拥有自己的愿望
- 形成危机前后的对照

## 检查一个危机是否有效

- 危机发生前，读者是否见过平静生活？
- 危机是否针对人物的具体弱点？
- 危机是否改变关系，而不只是制造伤亡？
- 危机结束后，生活是否留下长期影响？
