# 大事件的连锁反应

## 核心原则

大型事件不只负责制造战斗。它最好同时改变人物关系、主角目标、世界观认知和敌我格局。

## 事件设计表

| 影响层 | 事件造成的变化 |
|---|---|
| 个人 | 主角获得能力或留下创伤 |
| 关系 | 家人、伙伴或敌人的关系改变 |
| 地理 | 主角进入新的地区或社会 |
| 社会 | 阶层、国家或组织发生变化 |
| 世界观 | 揭开规则、历史或秘密 |
| 主线 | 产生新的长期目标 |

## 事件后的追问

不要只问“主角赢了吗”，还要问：

- 谁因此离开了？
- 谁因此成长或改变立场？
- 哪个旧目标被迫放弃？
- 哪个新问题无法回避？
- 主角对世界的理解哪里被推翻？
