# 配角与伏笔系统

## 配角设计

配角应该有自己的愿望、缺点、选择和生活轨迹。即使暂时离开主角视角，读者也要相信他们仍在别处行动。

## 配角的常见功能

- 导师：提供启蒙与方法
- 同伴：提供平等关系和刺激
- 家人：提供责任与牵挂
- 竞争者：暴露主角的自尊问题
- 政治人物：迫使主角理解现实
- 强敌：体现恐惧、宿命或历史代价

## 伏笔的三次出现

1. **第一次**：像普通信息，读者不一定注意。
2. **第二次**：在不同人物或地点处再次出现。
3. **回收时**：把分散信息组成新的解释。

## 好伏笔的标准

- 回头看能找到依据
- 当下出现不显得刻意
- 揭晓后能改变读者对过去的理解
- 即使没猜中，读者也觉得合理
