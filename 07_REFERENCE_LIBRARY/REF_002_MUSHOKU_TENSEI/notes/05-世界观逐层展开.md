# 世界观逐层展开

## 展开路径

`家庭` → `城镇` → `国家` → `大陆` → `世界历史`

让世界观随着主角的活动范围扩大。主角每前往一个新地方，都应该获得新的社会经验，而不仅是换一张地图。

## 每层世界观要增加什么

- 新的生活规则
- 新的利益冲突
- 新的种族或阶层关系
- 对旧知识的修正
- 一个更大的历史问题

## 记忆原则

先让读者看到人物如何生活，再解释这个世界为什么这样生活。

## 避免的问题

- 开篇一次性说明全部地图和历史
- 新地点只有风景，没有制度和冲突
- 世界设定与人物选择无关
- 设定只在作者需要时临时出现
