# 主角双成长线

## 能力线

主角越来越会做什么，例如战斗、魔法、知识、谈判、管理和领导。

## 人格线

主角越来越能够面对什么，例如失败、孤独、亲密关系、死亡、责任和过去。

## 最有张力的错位

主角可以能力很强，却仍然不会道歉、不会信任别人，或没有勇气面对失去。

这种错位避免了“实力提升等于人物完成”的单调感。

## 设计问题

1. 主角最大的能力优势是什么？
2. 这个优势会掩盖什么人格缺陷？
3. 哪个问题无法靠战斗解决？
4. 哪次胜利反而暴露了他的不足？
5. 到结局时，他学会承担什么责任？

## 记忆口诀

**能力让他赢，人格决定他赢了以后怎么活。**
