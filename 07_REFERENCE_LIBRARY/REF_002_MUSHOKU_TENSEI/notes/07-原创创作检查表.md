# 原创创作检查表

## 长篇骨架

- [ ] 我是否规划了不同性质的人生阶段？
- [ ] 每一阶段是否有独立目标和阶段性结局？
- [ ] 下一阶段是否由上一阶段的后果推动？

## 主角

- [ ] 主角的能力优势是什么？
- [ ] 主角最明显的人格缺陷是什么？
- [ ] 有什么问题无法靠能力解决？
- [ ] 主角最终学会承担什么责任？

## 剧情

- [ ] 日常是否建立了足够的情感基础？
- [ ] 危机是否改变了人物关系？
- [ ] 大事件是否同时推动至少三条故事线？
- [ ] 战斗之外是否存在真正的选择？

## 配角与世界

- [ ] 配角是否拥有不依赖主角的目标？
- [ ] 世界观是否随着主角视野逐层扩大？
- [ ] 伏笔是否有多次出现和合理回收？
- [ ] 是否已经避开原作的角色、名词、情节和关系组合？

## 最后复盘

每完成一卷，回答：

> 主角这次究竟变强了，还是变得更能承担自己的人生？
