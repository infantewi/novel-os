# 族群分布与社会歧视设计

> 本笔记整理自用户提供的英文材料。原文包含关于现实人类肤色、气候与进化的简化推测，这些内容不应视为严谨的人类学结论。这里主要提炼其对原创世界观、族群分布和社会冲突的启发。

## 一句话记忆

族群设定不只是外貌差异，还要解释他们住在哪里、如何流动、如何被看待，以及歧视是否已经进入制度。

## 个人偏见与制度性歧视

材料区分了两种层次：

### 个人或局部偏见

来自某个人、家庭、团体或地方组织的敌意、恐惧和排斥。

表现可能包括：

- 拒绝交往
- 侮辱和刻板印象
- 不愿提供服务
- 对某个族群产生不合理恐惧
- 因传闻而敌视具体人物

### 制度性歧视

当社会中的大型、可识别群体被法律、组织、经济制度或公共观念持续限制时，才形成更广泛的制度性歧视。

可能表现为：

- 限制迁徙和居住
- 禁止进入某些职业
- 不承认婚姻或继承权
- 司法处罚标准不同
- 教育和医疗资源不平等
- 宗教或国家公开宣传敌视某族群

两者都能制造剧情，但叙事意义不同。个人偏见适合表现人物冲突，制度性歧视则会影响整个社会的结构和历史。

## 不要把“没有某种族群”直接等同于种族歧视

一个世界没有现实世界中的某种族群，可能有多种原因：

- 地理隔离
- 历史迁徙不同
- 人口规模太小
- 种族或族群的分类方式不同
- 世界的生物起源不同
- 作者尚未展开该地区

但“没有某族群”并不自动代表世界没有偏见。判断歧视是否存在，需要看：

- 角色是否会因身份失去机会
- 社会是否把某群体视为低等或危险
- 法律和组织是否持续排斥他们
- 这种排斥是否影响角色的生活选择

## 族群分布的世界观逻辑

设计族群时，应同时考虑：

1. **起源**：他们从哪里来？是自然演化、迁徙、神造、魔力变化还是混血形成？
2. **环境**：他们适应什么气候、地形和魔力浓度？
3. **人口**：他们是多数、少数、流散群体还是孤立聚落？
4. **移动**：他们能否自由迁徙？谁控制通道、港口和边境？
5. **经济**：他们主要从事什么职业？资源如何交换？
6. **政治**：他们是否拥有自己的国家、领地、自治权或代表？
7. **文化**：他们如何称呼自己，外族又如何称呼他们？
8. **记忆**：历史战争、灾难和英雄故事如何影响今天的偏见？

## 地理与外貌差异

外貌差异可以来自气候与地理，但不要把现实世界的肤色简单归结为单一环境因素。原创世界还可以加入：

- 魔力长期改变身体
- 不同日照周期
- 多个太阳或特殊天空
- 人工迁徙与殖民
- 神明或古代文明的改造
- 种族间长期通婚
- 服饰、纹身、染发和宗教标记

外貌差异最好和生活方式、历史和社会身份一起出现，而不是只作为角色标签。

## 族群与“代表性”

读者可能希望看到与自己相似的角色，这种期待本身合理。创作者需要决定：

- 世界是否存在现实世界对应的族群？
- 他们是否只是背景人口，还是拥有重要角色？
- 角色是否会主动谈论自己的身份？
- 他们是否有内部差异，而不是统一性格？
- 他们是否只承担受害者、反派或异国风情功能？

较好的设计方式是让族群内部拥有不同阶层、地区、职业、价值观和个人选择。

## 族群冲突的三种写法

### 个体遭遇型

主角或配角在旅途中遇到偏见。重点是具体人物如何应对、误解如何产生、关系是否改变。

### 地方制度型

某个城市、宗教团体或国家对特定族群有明确限制。重点是制度如何影响工作、婚姻、教育和迁徙。

### 历史结构型

当前的偏见源于旧战争、资源争夺、宗教解释或长期宣传。重点是过去如何塑造现在，以及谁从这种制度中获利。

三种写法可以并存，但需要明确作品究竟想讨论个人偏见、社会制度还是历史创伤。

## 与《无职转生》式世界观分析的可借鉴部分

材料提供了一个有用的分析习惯：不要只问“世界上有没有某种人”，还要问：

- 他们为什么分布在那里？
- 为什么很少迁徙到其他地区？
- 当地人如何称呼他们？
- 他们有没有自己的社会网络？
- 其他族群对他们的印象来自亲身接触还是传闻？
- 这种印象有没有进入法律、宗教和经济？

这类问题能把“种族设定”从外观清单提升为社会世界观。

## 对原创世界观的启发

1. 族群差异必须和地理、历史、经济或魔力机制相连。
2. 个人偏见与制度性歧视要分别设计，避免混为一谈。
3. 不要用单一群体特征代表整个族群。
4. 让族群内部存在阶层、地区、职业和政治分歧。
5. 让歧视影响具体生活机会，而不是只停留在台词里。
6. 族群之间的误解可以来自传闻、历史创伤和现实利益。
7. 不同族群应拥有自己的视角，不只通过主角或多数族群被解释。
8. 族群设定应服务于人物、主题和冲突，而不是装饰性标签。

## 记忆口诀

**先问人从哪里来，再问住在哪里；先写如何生活，再写如何被看待。**

## 原创设计检查

- [ ] 每个族群的起源和迁徙史是什么？
- [ ] 他们的身体或外貌为何适应当前环境？
- [ ] 他们的人口规模和分布如何？
- [ ] 他们能否自由迁徙和通婚？
- [ ] 他们控制或依赖哪些资源？
- [ ] 他们在法律、宗教和经济中处于什么位置？
- [ ] 作品写的是个人偏见、制度歧视，还是历史创伤？
- [ ] 族群内部是否存在真实差异？
- [ ] 是否避免把族群简化为受害者、反派或异国装饰？
- [ ] 相关冲突是否会改变人物的具体选择？
