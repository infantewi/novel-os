# 人生阶段结构

## 核心方法

把长篇小说分成几个性质不同的人生阶段。每个阶段都更换主角的生活环境、身份、主要关系和核心问题。

## 典型递进

`家庭` → `学习` → `旅行` → `冒险` → `学院` → `家庭建立` → `组织与战争` → `终局与余韵`

## 每个阶段必须回答

- 主角此时的年龄、身份和生活地点是什么？
- 他想得到什么？
- 他最害怕面对什么？
- 谁会帮助他，谁会阻碍他？
- 阶段结束后，他失去了什么、获得了什么？
- 下一阶段为什么必然发生？

## 记忆口诀

**换环境，换关系，换问题，留下后果。**
