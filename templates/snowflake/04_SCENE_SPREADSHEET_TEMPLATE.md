# 雪花 Step 8：全书微观场景总清单 (Master Scene Spreadsheet)

> **原则**：小说不是写出来的，而是由一个个充满动力的原子场景搭建出来的。  
> **使用方法**：在动笔前，将全卷拆解为连贯的场景链条，每一行对应一个具备独立因果律的场景单元。

---

## 场景清单字段定义

| 字段 | 含义说明 | 规范要求 |
| :--- | :--- | :--- |
| **Scene_ID** | 场景唯一编号 | 格式如 `S001-01`, `S001-02`（卷-章-场） |
| **Chapter** | 归属章节 | 标明对应第几章 |
| **POV** | 核心视点人物 | **必须严格锁定单一角色**，严禁视点跳跃 |
| **Mode** | 场景模式 | `PROACTIVE` (主动型) 或 `REACTIVE` (被动反应型) |
| **Driver 1** | 第一推进力 | 主动型为 `Goal`（明确即时目标）；被动型为 `Reaction`（生理与情绪崩溃） |
| **Driver 2** | 第二推进力 | 主动型为 `Conflict`（阻力与冲突）；被动型为 `Dilemma`（两害相权困境） |
| **Outcome** | 终局结果 | 主动型为 `Setback` (No / No+ / Yes, but)；被动型为 `Decision` (进攻性抉择) |
| **Est_Words** | 预估字数 | 通常每个场景 1200 ~ 2000 字 |
